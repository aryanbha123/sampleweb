## About

`1.html` is a self-contained page with a jumping puppy, a cheerful message and a
button that opens a photo collage. Everything (markup, styles and script) is in that
one file, with the photos alongside it.

## Features

- Bouncing puppy emoji and a message card on a warm gradient background
- "Click me" button that opens a modal with a masonry-style photo collage (two columns, one on small screens)
- Emoji balloons that spawn every 600 ms and float up the screen
- Pure HTML, CSS and vanilla JavaScript, with no dependencies

## Project Structure

```
sampleweb/
├── 1.html        # the page
└── i1–i5.jpeg    # photos shown in the collage
```

## Run it

Open `1.html` in a browser. No build or install step is needed.
